Welcome to CryptoRocket

This is a real, live article — proof that the folder-drop workflow works end to end. Delete it whenever you're ready.

This post lives at posts/crypto/welcome-to-cryptorocket.html. It showed up on the homepage automatically because a GitHub Action scans the posts folder on every push and rebuilds posts.json, which the homepage reads to draw the ticker, the filter counts, and the article cards.

Publishing a new article

  • Copy posts/_template.html into the right category folder (sports, forex, crypto, or polymarket).
  • Fill in the post:title, post:date, and post:excerpt meta tags at the top of the file.
  • Write the article in the <article class="post-body"> section.
  • Commit and push to GitHub. Give it a minute — the homepage updates itself.
No dashboards, no CMS login, no build tools to install locally. Write HTML, put it in the folder, push.

See the README.md in the repository root for the full publishing guide, including how to add a new category.
